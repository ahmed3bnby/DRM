# ميزان — نسخة تأسيسية محلية

منصة امتثال لمكاتب المحاسبة والتدقيق متعددة الشركات. الاسم مؤقت. بيانات اصطناعية فقط؛ الفحص والفوترة والمستندات غير مفعّلة.

## التشغيل على هذا الجهاز

- PostgreSQL 17 موجود في `/opt/homebrew/opt/postgresql@17/bin`، وقاعدة المشروع داخل `.local/pgdata` على المنفذ 55432.
- إذا توقفت القاعدة: `/opt/homebrew/opt/postgresql@17/bin/pg_ctl -D .local/pgdata -l .local/postgres.log start`.
- `npm ci` ثم `npm run db:setup` ثم `npm run build` ثم `npm start`.
- افتح http://127.0.0.1:3000/login. بيانات حساب التجربة معبأة؛ اختر المكتب أو المدقق من الأزرار.
- `.env.local` يحوي أسرار قاعدة البيانات المحلية؛ لا ترفعه للمستودع. `.env.example` قالب فقط.
- `npm run db:setup` يعيد تعيين كلمات مرور الحسابات الاصطناعية؛ لا يستخدم في الإنتاج.
- للإيقاف: أوقف عملية التطبيق ثم `pg_ctl -D .local/pgdata stop` باستخدام المسار الكامل أعلاه.

## الاختبارات

`npm test` يشغل 8 اختبارات على قاعدة محلية مهيأة. `npm run typecheck` و`npm run build` يفحصان البناء.

`scripts/browser-check.mjs` اختبار محلي يعتمد Playwright المرفق ببيئة Codex وChrome المثبت؛ المسار خاص بهذا الجهاز. يستخدم حسابات اصطناعية وينشئ ملف اختبار؛ ليس إعداد CI محمولًا. اختبارات CI والنشر مرحلة لاحقة.

## الحدود الحالية

التشغيل مقيد ببيئة local واسم مضيف محلي. حسابات تجريبية وكلمات مرور معبأة عمدًا؛ لا تنشر هذه النسخة. الاختبارات لا تثبت الأمان الإنتاجي أو الحمل المتوقع. PostgreSQL RLS يحمي العملاء وسجلهم، ولا يغني عن تحقق الصلاحيات في الخادم. السجل لا يمكن تعديله بدور التطبيق، لكنه ليس تخزين WORM أو دليلًا على مقاومة مدير قاعدة البيانات.
