# تحليل الفجوات مقابل Idenfo — خطة التطوير

> مقارنة منصتنا (NBN) بمنصة Idenfo التجارية بناءً على لقطات شاشة حقيقية، مع خطة مرحلية.

## ما لدينا بالفعل (تحقّقت المطابقة) ✅
- فحص الأسماء: عقوبات · PEP · جريمة/إنفاذ · Special Interest · **Adverse Media (GDELT)**.
- تصنيف PEP بمستويات (Tier 1/2/3) + **RCA** (أقارب/مرتبطون) ببيانات حقيقية.
- **مصفوفة مخاطر العميل** (إقامة/جنسية/نشاط/قناة تعامل) + الأساس + الإجمالي.
- **حسم المطابقات** (مؤكّدة/مستبعدة/غير محسومة).
- **تقرير/PDF** بلوجو الشركة + سجل تدقيق (Activity Timeline).
- فريق/أدوار/حصص + بيانات حقيقية (٧٣٧ ألف سجل، ٤٦ قائمة).

## الفجوات (ناقص عندنا) — مرتّبة بالأولوية

### المرحلة A — مطابقة بصرية سريعة (أيام)
1. **بيدچات المخاطر بألوان + أسهم**: 🟢 منخفض (↓) · 🟡 متوسط (↔) · 🔴 مرتفع (↑). عندنا الألوان — نضيف السهم ونمط الـ pill.
2. **جدول Risk Factor Override**: صفوف صريحة (دولة الإقامة مُعاقَبة، الجنسية مُعاقَبة، إصابة عقوبات، PEP، Special Interest، Adverse Media، بلاغ معاملة مشبوهة STR) → «التجاوز إلى» → مستوى المخاطر → **Overall Rating**. البيانات موجودة (الأعلام + مخاطر الدول) — عرض فقط.
3. **قائمة فحص على الملف** (Sanction/PEP/Special Interest/Adverse Media ✓/✗) كودجت جانبي.
4. **حالة الملف كدورة**: مسودة → قيد المراجعة (Pending) → معتمد/مرفوض، ببيدچ ملوّن.

### المرحلة B — تدفّق عمل المحلل (أسبوع)
5. **Alerts Inbox**: صفحة تنبيهات = worklist المحلل. أعمدة: النوع، الاسم، الدولة، الفئة، **Aging (أيام مفتوح)**، حالة (فحص الأسماء / التوثيق / تقييم المخاطر) بعلامات ✓/✗/⚠، وزر **Review**.
6. **Aging**: عدد الأيام منذ الإنشاء/آخر فحص لكل حالة.
7. **Initiate Review**: إجراء يفتح مراجعة ويسجّل القرار النهائي والحالة.

### المرحلة C — عمق KYC (أسبوع+)
8. **Document Verification**: رفع/تتبّع الهوية والجواز + **تواريخ انتهاء** (تظهر بالأحمر عند الاقتراب) + حالة تحقّق.
9. حقول إضافية: **Is CRS · Resident Status · Other Nationalities · National ID/Expiry**.

### المرحلة D — العناية المعزّزة والعلاقات
10. **Enhanced Due Diligence (EDD)**: نموذج للعملاء عالي المخاطر (تدقيق الهوية، موافقة الإدارة، الدخل، الأصول، نطاق الاستثمار، العناية المستمرة).
11. **Associated Company**: ربط الأفراد بالشركات (المالك المستفيد/العلاقات).

### المرحلة E — تحليلات
12. **Insights Dashboard**: توزيع المخاطر، التنبيهات حسب العمر، معدلات الحسم، إلخ.

## خارج النطاق حاليًا (اتجاه منتج مختلف)
Idenfo فيها **Deep Link / Self-Service / Bulk Onboarding + Packages + Developer Tools/SDK** — دي منظومة **تسجيل ذاتي للعملاء** (onboarding عبر روابط). اتجاه كبير منفصل؛ يُؤجَّل.

## التوصية
ابدأ بـ **المرحلة A** (مطابقة بصرية سريعة، أثر عالٍ) ثم **B** (Alerts + Aging + المراجعة) — دول اللي بيفرقوا في تجربة المحلل اليومية.
