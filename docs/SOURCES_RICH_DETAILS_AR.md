# توسعة المصادر وتفاصيل السجل — 21 سبتمبر 2026

## ما نُفذ

- أضيفت 14 قائمة قابلة للبحث، وأعيد استيراد 11 قائمة سابقة من النسخ التفصيلية. الإجمالي 27 قائمة نشطة: 25 عبر OpenSanctions، ونسختان مباشرتان سابقتان للأمم المتحدة والمملكة المتحدة.
- 201,579 سجلًا في النسخ النشطة وقت التحقق. هذا عدد سجلات، وليس عدد أشخاص وشركات فريدين: هناك تداخل بين القوائم، وبين نسخ UN وUK المباشرة والمجمعة.
- الإضافات: كندا، سويسرا، أستراليا، نيوزيلندا (قائمتان)، اليابان، IDB، EBRD، البنك الأفريقي، CSL، BIS Denied Persons، SAM Exclusions، SEC PAUSE، SEC Harmed Investors.
- البحث العربي بالألف والهمزات ما زال يعمل؛ الأسماء الأصلية محفوظة للعرض.
- تفاصيل المصدر تشمل جميع الخصائص المتاحة: الهوية، الميلاد، وثائق التعريف، التسجيل، العناوين، المنصب، الملكية والعلاقات، الإدراج وأسبابه وروابط الأدلة. تظهر العلاقات في أقسام قابلة للفتح مع نوع العلاقة ومعرّفها؛ لا تُنقل هوية الطرف المرتبط إلى صاحب السجل.
- مصادر المعلومات لها اسم مزوّد، ناشر، صفحة أصلية عند توافرها، القوائم المساهمة، تاريخ رصد المزوّد، نسخة، وتجزئة SHA-256 للملف المستورد. تاريخ الرصد ليس تاريخ الإدراج الرسمي.
- صفحة المصادر تقارن النطاق المطلوب في المستندين بحالة الربط الفعلية؛ وجود قائمة في كتالوج المزوّد لا يعني أنها مستوردة.

## موثوقية الاستيراد

القارئ يرفض السجلات المعيبة أو المعرّفات المتكررة والملفات الفارغة؛ يتحقق من checksum المنشور عند توافر SHA-1، ويحفظ SHA-256 ونسخة خام محلية. ترقية القارئ لا تُتجاهل إذا لم يتغيّر الملف. كل استيراد داخل معاملة ويحافظ على التاريخ، مع حاجز انخفاض العدد السابق. فشل مصدر لا يوقف بقية الدفعة ولا يمسح النسخة النشطة السابقة. المزامنة الانتقائية تقارن مع آخر استيراد ناجح، فتُعاد محاولة المصادر التي فشل تحديثها.

لا تعني هذه الآلية وجود خدمة إنتاج للمزامنة المستمرة أو ضمانًا لاكتمال كل مصادر العالم. أوامر التشغيل المحلية:

```sh
npm run sources:sync:changed
npm run sources:sync
```

## ما لم يكتمل

- Companies House: مفتاح API وربط فعلي.
- ICIJ: استيراد قاعدة العلاقات الكاملة وإسنادها؛ لم يُستبدل بعينة صغيرة مضللة.
- FCA وDOJ: موصلات التحذيرات/الإنفاذ الرسمية.
- SEC: المستورد PAUSE وHarmed Investors فقط؛ سجل Litigation Releases الكامل غير مربوط.
- Wikidata: ربط انتقائي للمناصب والعلاقات.
- PEP/RCA: التغطية الحالية في هذا الجزء مجالس قطر والبحرين وعُمان، وليست قاعدة عالمية مكتملة.
- الأخبار السلبية: مزوّد وتغطية وترخيص.
- بيانات الشركات العادية: GLEIF يبحث مباشرة في الكيانات ذات LEI فقط؛ لا يغطي كل سجل تجاري أو جميع الملاك المستفيدين.
- ترخيص OpenSanctions المناسب لخدمة SaaS لإعادة البيع لم يُفعّل. إتاحة التنزيل للتقييم لا تمنح تلقائيًا حق الاستخدام التجاري: https://www.opensanctions.org/licensing/
- تطوير دقة المطابقة وقرار المحلل والتعامل مع حد النتائج (51 مرشحًا حاليًا) من أعمال المراحل التالية، وليس ضمانًا قدمته توسعة البيانات.

## التحقق

- 10 اختبارات Python لقراءة المصادر، منها حفظ العلاقات والأدلة ومنع خلط هويات الأطراف.
- 16 اختبار تطبيق ناجحًا، تشمل عزل الشركات والبحث بالهمزات وسلامة روابط الأدلة وحالة التغطية.
- فحص الأنواع وبناء الإنتاج ناجحان.
- تحقق متصفح: جدول النطاق المطلوب، البحث في كندا، سجل إماراتي بعناوين وإدراج متداخل، فتح التفاصيل، وعدم وجود تمرير أفقي على الهاتف أو أخطاء صفحة.
- تقرير الأعداد والنسخ: `docs/evidence/rich-source-check.json`.
