# مراجعة التعديلات الحالية — 21 سبتمبر 2026

راجعت الملفات الموجودة محليًا وقاعدة البيانات الحالية، وليس سجل المحادثة المنقول وحده. المشروع بلا مستودع Git؛ لذلك لا يمكن استخراج فرق موثق بين نسختين أو نسبة كل تعديل لأداة بعينها.

## المنجز المفيد

- رأس ملف العميل أوضح: نوع الكيان والدولة والميلاد والمعرف.
- إزالة عنصر الفحص المقفول من القائمة مناسبة لوجود زر فحص عامل داخل الملف.
- استيراد OpenSanctions أضاف قوائم فعلية، وسجل الاستيراد أفضل من كروت اختبار الاتصال القديمة.
- وقت المراجعة: 13 نسخة قائمة نشطة في القاعدة؛ تشمل UN وUK المباشرين، ونسختيهما عبر OpenSanctions. العدد لا يعني 13 مصدرًا مستقلًا ولا اكتمال المصادر المطلوبة. القوائم الخليجية PEP الحالية مجالس قطر والبحرين وعمان فقط.

## إصلاحات نفذتها في هذه المراجعة

1. بحث العملاء صار يستخدم اسمًا موحدًا للبحث، ويحتفظ بالاسم الأصلي للعرض. أعدت فهرسة الأسماء المحلية، وأضفت اختبار اختلاف أ/إ/آ/ا والتشكيل وعزل المكتبين.
2. اختبرت الاسم الذي ذكره المستخدم بخمس صيغ همزات في مصادر البيانات: جميعها تعيد السجل المحتمل نفسه عبر اسمه البديل العربي. اسم السجل الرئيسي معروض بالإنجليزية؛ هذا لا يعني أن البحث العربي فشل. لم تثبت هذه التجربة أن السجل هو هوية العميل المقصود.
3. استبدلت علامة «نظيف» الخضراء عند غياب الإشارة في بطاقة ملف العميل بشارة محايدة. التاريخ الحالي لا يحفظ اكتمال التغطية لكل فئة؛ لا يمكن تحويل false إلى إثبات فحص شامل.
4. أصلحت تحذير بناء ناتج عن قراءة مسارات ديناميكية واسعة في sources.ts.

## التغطية والترخيص

التكامل الحالي للقائمة الإماراتية قابل للبحث عبر OpenSanctions؛ موصل EOCN ينزل PDF دليلًا فقط ولا يحوله إلى سجلات بنفسه. يجب عرض هذا الفرق بوضوح.

وصف البيانات بأنها «مجانية» لا يثبت حق بيعها داخل المنصة. صفحة OpenSanctions الرسمية تميز ترخيص إعادة البيع عن الاستخدام الداخلي: https://www.opensanctions.org/licensing/ . يلزم تثبيت حق الاستخدام المناسب لخدمة مكاتب متعددة، دون افتراض أن استيراد البيانات يغطيه.

## ترتيب العمل المقترح

1. دقة البحث والأدلة والتغطية: إزالة قص الفحص، معرفات وتواريخ صحيحة، حالات فشل واضحة، منع ازدواج القوائم.
2. اكتمال التفاصيل ومصادرها: العناوين والمناصب والعلاقات والأخبار بحسب التغطية الفعلية.
3. قرار المحلل والتقارير القابلة لإعادة الإنتاج.
4. تعديل العملاء مع سجل تغييرات وإعادة فحص.
5. استكمال كل المصادر المطلوبة، ثم متطلبات تشغيل SaaS: العضويات وMFA والفوترة والنسخ الاحتياطي واختبار الحمل.
